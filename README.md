# 🎣 Bigger Bass Splash

Анімований слот-проєкт із захоплюючим візуалом та взаємодією з користувачем.  
Містить сторінку завантаження, головну ігрову сторінку, а також перевірку на виграш з відповідною візуалізацією.

---

## 🚀 Функціонал

- 🎰 Анімація обертання слотів
- 🧠 Логіка перевірки на виграш
- 💥 Анімоване поле при виграші
- 🪄 Модальні вікна з анімованим текстом (тайпер) для залучення користувача
- ⌛ Сторінка завантаження з анімацією
- 📱 Адаптивна верстка
